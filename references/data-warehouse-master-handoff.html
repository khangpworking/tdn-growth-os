10. Key Normalization Rules

  • Store monetary values twice: raw string + normalized DECIMAL(20,2) VND.
  • Store IDs as strings (exceed JS-safe integer range), not numeric.
  • Normalize compact values (k/m/b) to numeric while preserving raw.
  • growth may be % or comma-separated daily trend series → split into growth_pct + child trend table.
  • Creator conversion appears as 50.00%, 1, or 0.5 → normalize.
  • Keep source_endpoint, scraped_at, period_start/end, cached, HTTP status, raw-response hash for lineage.
  • Preserve raw JSON in a bronze layer; build typed silver/gold tables from it.

7. Notes

  • Interest scores relative (0–100): 100 = peak popularity for query+region+time.
  • Max 5 queries per request (TIMESERIES, GEO_MAP); other types accept 1 query.
  • SerpAPI caches 1 hour — cached requests free (not counted).
  • Custom date ranges support hourly granularity within 7-day window: yyyy-mm-ddThh yyyy-mm-ddThh.
  • gprop=youtube → YouTube-specific trends (creator strategy).
  • Rising queries with "+X,000%" indicate breakout trends (near-zero prior volume).
  • Related topics provide entity knowledge-graph data (category expansion).
  • include_low_search_volume is critical for Vietnam — many regions default to low volume.
