# Reader-report v1 assets

`be-vietnam-pro/` holds Be Vietnam Pro normal 400/600/700/800, Latin, Latin
extended and Vietnamese subsets, copied byte-for-byte from
`@fontsource/be-vietnam-pro` 5.3.0. The original SIL Open Font License is in
`be-vietnam-pro/LICENSE`. The reader report embeds them as data URLs, so the
page never calls a remote font service.

`icons/` holds the Shopee and TikTok marks from Simple Icons (CC0 1.0). The
marks themselves remain trademarks of their owners; they are used only to tag
which marketplace a number comes from.

Do not replace these files in place. A later presentation profile gets a new
versioned folder so retained v1 reader reports rebuild against the same bytes.
