# Report-kit v1 typography

Montserrat normal 400/700, Latin, Latin extended and Vietnamese subsets were
copied byte-for-byte from the owner's report-kit `@fontsource/montserrat` 5.3.0
assets. The original SIL Open Font License is included in `montserrat/LICENSE`.

They are embedded into the new, script-free report presentation. No browser
font download or external font service is required. Do not replace these files
when introducing a later presentation profile: retained v1 reports rebuild
against these exact versioned bytes.
