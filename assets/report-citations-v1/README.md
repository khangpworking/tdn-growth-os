# Citation-preview report fonts

Exact font bytes copied from the owner-approved report kit's installed
`@fontsource/montserrat` version 5.3.0, SIL OFL 1.1. The license is retained in
`montserrat/LICENSE`. All 21 copied WOFF2 files were byte-hash compared with
that source installation without modification.

Subsets: Vietnamese, latin-ext, latin. Normal weights: 400, 500, 600, 700, 800.
Italic weights: 600, 700. The preview embeds them as data URLs for offline use;
it does not require a Fedora font package or a remote font/CDN request.

This namespace belongs only to `report-kit-citations-preview-vi-v1`.
`assets/report-kit-v1/` and historical renderer output remain unchanged.
