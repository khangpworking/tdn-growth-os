# Citation preview surface

Extends the approved Vietdata market-report and YouNet ECI insight-report presentation. It is not a new visual direction and does not replace the app-shell design system.

Primary action: a reader follows a numbered reference beside an existing quantitative fact, inspects its stored calculation, and follows related references to the exact source cells. No generated conclusion or source authenticity claim is added.

Numbering is deterministic for one exact content version, not a permanent number across later report versions. Each citation retains its semantic version, file hash and locator. Technical hashes are disclosed on demand, not the primary reading experience.

Keep the existing navy/blue/yellow market palette and pale/navy/cyan/orange insight palette. New controls use Montserrat, visible focus and ordinary document anchors; there is no hover-only interaction or new script permission. Mobile reading must not produce horizontal page overflow.

Empty/blocked sections retain their actual state. The preview banner states that design approval is pending. The source register distinguishes calculations from retained sources and provides downloads that exist in the exported bundle.

Design judge: the existing Claude Code session **Competitor mockup report design**. Final approver: owner. No deploy from a synthetic screenshot or compiler-only PASS.
