## Direction contract

THESIS: A number can be inspected, not merely believed. Show observed totals and
their limits together, then expose the exact calculation and original source.

OWN-WORLD: Existing TDN navy text, white reading surface, blue links and teal
data marks. Restrained system typography, aligned tabular numbers and light
separators; no decorative imagery or new tokens.

STORY: Read the period and draft boundary, compare separate scope bars, inspect a
claim, then follow membership to source rows and download the retained workbook.
Blocked sections explain missing prerequisites without pretending completion.

FIRST VIEWPORT: Report title and explicit draft state, period/filter/acquisition
metadata, a compact four-layer evidence legend, then revenue/unit chart pairs.
Each numeric observation is a labelled link to its evidence. No giant KPI hero.

FORM: Narrow data-view extension of the existing overview/detail world; no seed
required. Native details disclose evidence; anchor navigation is the signature
interaction. No animation or JavaScript is necessary. Mobile stacks charts;
print retains limits, tables and evidence rather than decorative navigation.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

## Limits and acceptance

- Static internal HTML export, not an official approved report or deployed route.
- Only current calculation handlers plot data. No market-growth or causal chart.
- ALL/WIDE/CORE overlap; Top 1/3/10 shares are cumulative. No stacked totals/donut.
- Values stay exact strings; chart lengths use bounded integer ratios only.
- Missing and zero differ visibly; scope and acquisition limits remain visible.
- All source strings inert and escaped. No external resource or script loads.
- Inspect actual Linux-produced synthetic output at desktop and mobile before
  claiming visual acceptance. No Windows build/test/typecheck.
- Existing PRODUCT/DESIGN historical capability descriptions and Impeccable
  sidecar drift are pre-existing; do not silently rewrite them as part of this.
