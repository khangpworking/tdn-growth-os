## Boundaries

Rule fields start blank. No product-specific rule or label is invented. UNKNOWN
needs explicit acceptance and stays outside WIDE. Pending cannot become UNKNOWN.
At most 100 explicit rows per proposal/acceptance. No automatic batch writes.
New classified reports require the entire source universe, reuse both retained
sources, preserve the prior report and reuse the retained Insight AI execution.
Uncertain writes hold the exact request in memory for explicit retry. No token
or raw draft persists in browser storage. No deployment or real approval here.
