Mode: Operate. This extends the existing research dossier, not the report's
visual design or the app's navigation. Preserve DESIGN.md and its sidecar.

## Direction contract

THESIS: Separate viewing an immutable version from requesting another one.
The original remains the default; no hidden latest selection or automatic retry.

OWN-WORLD: Existing navy text, white surface, blue actions and teal focus.
Use existing native fields, report links and confirmation dialog.
ENERGY 1 / RHYTHM 1 / MOTION 1; no imagery or new typography.

STORY: Choose an exact saved pair, view/export its Market and Insight outputs,
then explicitly choose retained sources for a new pair with unchanged scope.
Reload restores the server's active attempt without submitting it again.

FIRST VIEWPORT: A named version selector precedes its two report actions.
Attempt status and the optional source-upload disclosure precede the final
create action. Existing run progress and coverage remain present.

FORM: Narrow established-world extension, no concept seed. The signature is a
frozen source/predecessor request that can be explicitly retried after uncertainty,
while web and PDF remain bound to the user's selected pair.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

## Acceptance scope

No recollection, source-provider/model call, scope edit or original-output write.
Fresh creation is held while authoritative reads are stale or catching up to a
commit. Upload stores only; subsequent confirmation admits its exact package.
Failed/cancelled attempts do not masquerade as successful versions. OWNER stays
memory-only. Pending work is discovered by read-only inventory after reload.
An in-memory uncertain request is not promised recoverable after full navigation;
retained attempts/packages are discoverable and never adopted implicitly.
