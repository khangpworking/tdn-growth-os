# Research A44: bounded gates and decision packets, wave 3

Date: 2026-10-01. Authorized continuation of the adopted A42 delivery plan.
Base: A43 `6583b6dd1fbed70bc5d41d1fb81dc287ba62a4e2`, draft PR #102.

## Scope

Complete bounded code paths for the nine remaining sections: M10, I11, I12,
I16, M01, M11, M12, I14 and I15. This is not approval to execute advanced
analysis, generate AI interpretations or make business decisions.

M10 reports structural eligibility and missing policy only. Forecasts and the
proposed baseline/MAE remain disabled. I11 retains source-assigned group cells
without inferred membership, rates, differences or public-release authority.
I12 keeps presence, exposure and outcome inventories separate, with no join,
conversion or effectiveness calculation. I16 retains design-only metadata or
existing-result eligibility, never an estimated effect in this version.

The five synthesis sections compile exact existing calculation claims and
owner-declared groupings/options. Their input claim projection is deliberately
limited to the verified packet FACT observations in this first version.
Input references bind the exact `metric-result.json` digest and an explicit
`claimPointer` in the current packet. The report boundary verifies both artifacts
and the entire pointed FACT payload. The retained output also binds the current
packet digest. A descriptor in a source package must not reference the digest of
the package-dependent packet itself: that would create a circular hash dependency.
Unreviewed claims remain visible but do not become reviewed support. Imported
review declarations do not authenticate approval. Unknown cost, capability,
time and risk stay unknown. Priority, preference, conclusion, chosen action
and execution authority stay null or open. No provider/AI path is added.

Authority: unchanged A41 advanced and synthesis profiles, scoped adoption and
the nine A40 recipes. Missing run inputs block only the affected output.

## Ownership and integration

- Gate lane: its new canonical schema, pure methods, fixture and owning tests.
- Synthesis lane: its new canonical schema, pure methods, fixture and owning
  tests; exact packet claim payloads, not free-form invented facts.
- Coordinator: contract registration, retained-source verification, service
  and semantic integration, renderer, shared files, Linux CI and release notes.
- A free worker performs independent review after implementation.

At most three workers beside the coordinator. No worker commits or pushes.
The three resumed code/review lanes use GPT-5.6 Luna xhigh. The owner's
2026-10-01 assignment update routes delegated design/UI/UX work to Claude
Opus 5.5 high, and code/logic to Claude Sonnet 5.5 high or GPT-5.6 Luna xhigh.
Do not substitute Astra or silently replace an unavailable requested model.
No Windows tests, typechecks, builds or browser execution. Use Linux CI.

Report integration reuses the existing ledger and exact retry/replay boundary.
The existing 40-artifact limit must not be raised. If an additional bundle
would exceed it, select a single combined method-evidence bundle for the new
request path, preserving the old rendering/file path when that path is absent.
Do not change migrations, dependencies, or existing source bytes.

## Acceptance

Own behavior at its real boundary: missing versus zero, split/calendar gaps,
incompatible units/periods, source assignments, separate exposure/outcome,
design-only null results, claim identity, counterevidence, owner option order,
unset constraints and no automatic choice. Retain canonical input/output bytes
and prove exact replay. Service integration owns source/package identity and
retention; pure unit tests do not substitute for it.

Keep the approved report style and clearly distinguish a useful inventory/gate
from a complete analysis. No estimated result is rendered for a blocked method.
No merge, deployment, live migration, source upload, provider call, paid action
or actual business decision is authorized here.
