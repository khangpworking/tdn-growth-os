# Native review SourcePackage automation slice

## Authority and purpose

Business advice in turn `01a0fd6a-df2c-74a0-bd8b-b72aaaa7b247` confirms the
internal connector under the approved A41 plan. Owner input remains product and
exact listing selection, not package IDs, JSON or per-review labels. This slice
connects the already retained native Dami source to saved Market/Insight output.
It does not acquire new data, authenticate authors or complete 30 sections.

## Narrow implementation

1. Enumerate through the existing Foundation package reader. Admit only the
   native mapped-source shape and reviewed mapper bytes, exact selected shop/item
   IDs, raw capture membership and descriptor records. Reject derived method
   overlays as new original sources. Do not choose by title, timestamp or version.
2. Freeze exact source identity in the collection result. No fabricated Zen
   collection, provider request receipt or market-period admission is allowed.
   Multiple distinct matching captures remain an explicit ambiguity; a failed
   resolution does not automatically trigger another paid collection.
3. Retain an independent run-bound declaration overlay through Foundation,
   preserving original source bytes/metadata, complete pending diagnostics and
   adopted policy/implementation identity. Historical replay reads retained
   outputs, not current literal parser, mapper or projector execution.
4. Render genuine native coverage/source context in I03/I17 and declarations in
   eligible Insight sections. Keep separate paired report files, PARTIAL status,
   zero analytical completion and original source limitations.

## Ownership and dependencies

GPT owns service/model/report composition; a delegated GPT lane owns the new
native bridge and its source-bound tests. Shared contracts, existing pinned
mapper/projection/wrapper bytes, migrations and dependencies are not changed.
An independent read-only audit follows integration, before publication.

## Acceptance

Use synthetic Foundation packages at the service boundary: correct native
source, wrong listing, derived overlay, ambiguous distinct captures and corrupt
retained data. Prove exact original source binding, no Zen/provider call for
native reuse, safe declarations/pending in saved HTML and unchanged historical
bytes with zero replay mutations. Run affected tests and typecheck only on Linux;
expand to the full Linux release check after integration is stable. Then run an
isolated actual Dami acceptance with no new provider or active-runtime writes.

## Exclusions

No deployment, restart, live migration, provider call, new owner decision,
source-authentication claim, customer prevalence, unique people, annual/category
coverage, final AI conclusion, Claude design approval or owner report approval.
