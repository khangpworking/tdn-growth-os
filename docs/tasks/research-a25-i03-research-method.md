# Research A25: I03 research-method account

## Outcome

Materialize I03 as a deterministic, replay-bound account of how one exact
Metric source package becomes the normalized rows and calculated scopes used by
the report.

The method artifact records source inventory, package and artifact identities,
normalization profile, measurement frame, explicit denominators, missing versus
zero and non-exact counts, label states, ALL/WIDE/CORE membership conditions,
limitations and reopen conditions. It is part of packet, semantic, report
version and interpretation replay identity and appears in the HTML report.

## Truth boundary

- Source bytes and locators are evidence provenance, not provider authentication.
- Normalized and calculated values are reproducible application outputs.
- I03 creates no finding, insight, recommendation, causal claim or approval.
- A blocked WIDE or CORE scope is displayed as blocked, not as an observed zero.
- UNKNOWN remains visible and follows the frozen `wideUnknownPolicy`.
- Existing report versions keep their original catalog and method requirements.

## Verification ownership

The existing source-backed integration case owns package-to-I03 lineage,
denominators, blocked-scope rendering, immutable replay and downloads. The
report-version integration case owns the resulting 30-section readiness count.
The M02 unit case owns the source-period date-time boundary. No duplicate
browser or unit replay suite is added.

Linux Check and the research-report preview are release gates. Windows is used
only for contract generation and static diff inspection.
