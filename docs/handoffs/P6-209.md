### Capture design

`capture` now performs one search, waits for the results page after a successful
filter read-back, reads the combined view and any offered Shopee/TikTok Shop
views, then archives immediately outside the repository. It never opens a
result-panel action. Network response JSON is preferred; DOM text/table data is
the fallback. Each normalized field carries a `response:/path` or `dom:selector`
source pointer. Raw response output keeps bodies and URL paths only, with
credential-shaped fields stripped. The archive also contains the saved HTML,
per-region screenshots and a manifest.

Product tables are paged per platform view until completion or a sane cap of
200 rows / 10 page turns. The manifest records `totalShown`, `rowsRead`,
`pagesRead`, `cap` and `truncated`.
