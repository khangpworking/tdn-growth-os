# P5 retained synthesis and JEV shadow checkpoint

Date: 2026-10-03. Baseline `0116091fd5dc0902594f92d969dfb3ee0732c9c8`.
This is cumulative uncommitted work on `fix/research-real-world-audit`, not a
release, deployment or completed R1/R2 acceptance.

## Scope

The Analysis report owner now wires the optional I14 execution helper after
building claims and admission from its exact frozen source/method readers. No
public endpoint accepts arbitrary synthesis evidence. The default transport is
null; the operator has not been configured to send real report evidence to AI.

Migration 0042 adds one execution subrecord for an initial report or exact
supplemental attempt. It retains admission, model input, prompt and non-secret
configuration before the dispatch claim. Successful validation retains the
defined candidate envelope, not hidden reasoning or arbitrary provider payloads.
Invalid responses retain a safe validation code; ambiguous dispatch is terminal
for that identity. Report publication references only a settled execution.

Read and PDF access rebuild the admission through the owning source readers and
verify the referenced execution and retained artifacts without model calls.
Recovery marks ambiguous dispatches before requeuing deterministic rendering.
Current configuration is not authoritative for historical response replay.

The report labels candidates as unreviewed AI proposals, shows assumptions,
unknowns and support/counterevidence links, and escapes model prose. Schema and
reference checks do not establish that the prose is true. No owner direction,
ranking, model promotion or business approval is introduced.

## Design correction

Impeccable findings covered mobile comparison-table readability, duplicate
limitation codes and excessive visible trace metadata. M01/I14 now show each
complete record vertically on narrow screens. Original quotes remain visible;
metadata and exact limitation codes use nested native disclosures. PDF rendering
already opens all disclosures, so this does not remove retained source detail
from print. Approved report-kit typography and colours remain unchanged.

The first Linux confirmation rendered all three synthetic industry fixtures:
4/4 tests passed, then 8 browser captures at 1440 and 390 px passed with no page
errors or document overflow. The mobile evidence table itself was checked for
overflow and readable cell bounds. The final batch and retention integration
still require the checks recorded below; that first result is not final proof.

## JEV: optional shadow only

Eight requests were made: one model-catalog request, six synthetic classification
fixtures and one exact repeat. All six top choices matched predeclared toy
expectations. The repeat kept the label but changed probabilities. Classification
latency was 304–627 ms; provider-reported totals were 3,466 input and 453 output
tokens. Cost was not reported and is not inferred from an unverified rate.

All classification responses echoed `jev-1.13.0`; the catalog exposed aliases
rather than that pinned ID. Resolve this provider/version contract before a
larger pilot. Ambiguous praise and injection-like text had uncertain probability
distributions. This is not an accuracy benchmark or evidence for promotion.

Artifacts remain outside Git under
`artifacts/research-execution-20261003/jev-shadow/`. No private source, token,
credential, accepted label or production configuration was changed. J1's
holdout, baseline comparison and business-reviewed labels remain open.
