## Completed work

Snapshot-only builds now reach the application with `reader-report-build-v1.1`. The existing `reader-report-build-v1` requires source and forbids snapshots. Canonical API/input schemas enforce version rules and generated types were regenerated. The application validates snapshot shape and canonical digest, derives source, rejects a conflicting supplied source, checks the derived period against the retained workbook and maps snapshot errors to validation errors. Complete request hashing preserves exact retries and request-key conflicts. Workbook lineage is derived from retained context bytes, not a caller-provided hash.

Monthly comparisons require values in six consecutive calendar months, including the latest dated month. Gaps/nulls suppress the comparison. Flint and SVG fallback retain gaps; fallback is a line chart with no fabricated zero point. Missing platform values stay missing.

The 1.1 renderer cites retained sample measurements, source rows with sheet/cell locators, web facts/table rows/chart captions/web results/quoted snippets. Without retained sample lineage it says "Chưa có nguồn". Sample labels match P1: "Dòng số liệu nguồn" and "Số liệu đã tính từ nguồn đã lưu"; web labels use a safe site or "Kết quả tìm kiếm trên web". Neutral group locators prevent all snapshot groups collapsing into the first citation. Finished-page numbering is applied to HTML, narrative logs and bundled citation values. One register appears after the source-row appendix; PDF links print as text.

Rounded web values carry precision notices beside the number, including previously uncovered leader/brand tables. R1–R4 mismatch warnings now use bundled measurements and the Narrator, with separate sample/KPI/platform citations and precision notices. R4 displays Shopee/TikTok Shop. W1 checks the matching exhibit div, W2 rejects cross-family arithmetic even with coverage wording and grouped digits, W3 rejects a summed-platform statement even when it carries a family label, and W6 checks every prohibited captured-provider name plus encoded attributes. Sentence checks retain digit separators and paragraph/table-row boundaries; grouped forecast amounts remain subject to W5.

The legacy fixture remains byte-identical to the original renderer at `42b2787`: SHA-256 `e2094fdf8d70fb529f5bdd7db974bbe475839693086506a662a4ae8e48682535`. Stored pages read back from verified original bytes; no historical page is regenerated.
