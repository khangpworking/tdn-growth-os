## Summary of changes

- Contract `reader-report-input` accepts `1.0.0` or `1.1.0`. `webSnapshot` (opaque object) and `webSnapshotSha256` are optional in the schema; the version rules are enforced by `verifyReaderReportInput` (1.0.0 requires `source` and forbids snapshot fields; 1.1.0 requires snapshot+sha and `source` is optional). Generated file regenerated with `npm run contracts:generate` (idempotent, sha `6aca6c46` before/after re-run).
- New `src/modules/analysis/reader-report/web-facts.ts`: `ReaderSourceError` (`READER_SOURCE_UNDERIVABLE` / `READER_SOURCE_MISMATCH`), `verifyWebSnapshot` (schema + sha256(canonicalJson) check), `deriveReaderSource` (period from scope, 4 headlines from W2, breakdown from W3; null names the field, never 0), `checkDerivedSource`, `setWebBundleKeys` (all `web.*` keys, platforms never summed), `webMonthlyStats` (peak/low/last3vsPrev3), `reconcileWebWithRows` (R1–R4 warnings `METRIC_WEB_XLSX_MISMATCH` with numbers).
- `build.ts`: version-gated verify, `ReaderReportData` gains `webFacts`/`webKeys`/`webReconciliation`; 1.0.0 path untouched (no web keys, byte-identical render).
- `market-template.ts`: conditional web exhibits M01 (full-result key line; monthly gap sentence replaced only when W4 has valued months), M02 (W1 scope table 2.3, coverage line with `phủ`, monthly method, reconciliation note), M03 (KPI table 3.2, per-platform Flint monthly chart 3.2, peak/low note), M04 (category/shop-type/location tables 4.2–4.4), M06 (top-10 shop table 6.3), M07 (brand share 7.2, brand×shop-type 7.3, leader tables 7.4–7.6 with rank change and growth), M08 (page price table 8.3, separate from `MARKET_PRICE_BANDS`), M09 (W4 momentum rows; per-entity confidence stays `Thấp` unless W16), M10 (past trend only, no forecast numbers), M13 (snapshot source line + `Nguồn tham khảo` register, pdf format so links print as text). Every web number goes through the bundle (`{{web.*}}` in narrative, `B.f` in tables); captured text goes through `L()` into `extraOk`.
- `lint.ts`: W1 (webex blocks carry `toàn kết quả tìm kiếm`), W2 (no cross-family math except the M02 `phủ` coverage line), W3 (no summed platform total the page did not show), W4 (no unnegated `thị phần`, same negation rule as F5), W5 (no forecast number in M10, per-sentence), W6 (no provider name in captured `data-web-label`). Pages without a snapshot pass all W-rules unchanged.
- `bundle.ts`: `notInBundle` also accepts sign-stripped forms so negative changes (e.g. `-5,2%`) match their bundle entry.
- `reader-report-revisions.ts`: passes an optional snapshot through, maps `ReaderSourceError` to a validation error, and checks the effective (derived when 1.1.0) period against the attached file.
- Citations: one `CitationRegistry` per `buildMarketReport` call; one citation per rendered snapshot group (identity = `webSnapshotSha256`, neutral Vietnamese labels, no codes/digests); `[n]` marks via bundle `cite.web.*` keys inside narrative and `renderCitationMark` in tables/captions; register appended in M13. Numbering is per report and deterministic (two builds give the same sha).
- Tests: new `tests/unit/reader-report-web.test.ts` (10 tests). Updated one assertion in `tests/unit/reader-report-kit.test.ts` (`results.length` 9 → 15: the 6 new W-rules; listed per G-11).
