# Source-bound literal declaration projection

## Scope

The new pure Dami field mapper and separate literal projection overlay use the
existing Foundation SourcePackage and Located contracts. There is no migration,
second source ledger, competing semantic schema or fabricated Zen collection.

The mapper verifies transport bytes, exact review row type, safe listing IDs
and comment pointers, preserves source dates and native metadata, and
quarantines conflicting native IDs. It does not authenticate authors, infer
variants, join products by name or admit a period/category.

The projection uses the independently accepted grammar tuple and adopted
`literal-source-bound-v1` policy. It selects only eligible source-bound
DECLARED candidates. Pending blocks the affected reading; unrelated pending
does not veto useful declarations. Unknown scope stays conservative. Exact
annotations, qualifiers, counterevidence, UNKNOWN and all pending diagnostics
remain intact. Clause conflicts cannot silently choose one reading.

The SourcePackage wrapper checks the exact accepted tuple and policy bytes,
binds source/descriptor/coding identity, and prepares a separately identifiable
PARTIAL output with original diagnostics. It makes no database/provider call.
Original proposal artifacts retain their authority labels and bytes.
