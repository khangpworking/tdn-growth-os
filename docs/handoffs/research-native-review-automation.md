# Native review automation handoff

## Completed scope

GPT resumed the work after Claude quota exhaustion. The new internal bridge
resolves one exact confirmed Shopee listing to its retained original Dami
SourcePackage through declared Foundation readers. It does not require owner
package IDs, per-row labels, another provider call or a fabricated Zen corpus.
Business authority is the accepted A41 advice recorded in turn
`01a0fd6a-df2c-74a0-bd8b-b72aaaa7b247`.

The collection result freezes source identity and capture/descriptor/mapping
bindings. Report creation retains a separate immutable run-bound declaration
overlay, preserving original bytes, roles, provenance and complete diagnostics.
Historical reads validate frozen source and output relationships, not today's
semantic parser/projector. Saved older reports are not regenerated.

Native source context is rendered in I03/I17; eligible adopted declarations and
pending diagnostics use the existing Located report renderer. Market and
Insight remain separate web/PDF artifacts. No section completion is promoted.

## Failure behavior and review

- Ambiguous matching originals, unsupported multi-listing native scope or a
  failed retained inventory are explicit blockers, not permission to recollect.
- Cancelling during asynchronous source reads settles the claimed collection.
- Rejection of independent market observation lineage cannot discard a native
  source that passed its own verification.
- Method publication failure explains that the source is retained, instead of
  asking the user to add the same listing again.
- Oversize inline/native presentation retains a compact package reference and
  produces both reports with an explicit failure notice. The complete method
  package is preserved. Package-bounded historical reconstruction does not
  incorrectly apply the smaller inline-document limit.

Independent read-only review closed the cancellation, oversize, source-isolation,
failure-notice and reconstructed-size findings, with no new actionable finding
on the final code. Source authentication, complete-history coverage and final
approval are not conclusions of that review.

The existing Foundation list API verifies its bounded entire inventory. A
corrupt unrelated package can therefore block new native resolution; this is
reported as an integrity failure, not false source absence. Historical replay
reads its frozen packages directly and does not enumerate a current inventory.
