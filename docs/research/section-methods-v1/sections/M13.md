# M13 · Phụ lục và truy nguồn

Spec v1.0.0 · coverage `DRAFTED` · authority `EXISTING_BOUNDED_SUBMETHOD` · implementation `EXISTS_A23` · readiness `NOT_ASSESSED` · execution/review `NOT_RUN`.

## Question and boundary

Which exact retained source file and locator supplies each normalized record, revenue observation, unit observation and optional label? A23's deterministic appendix owns the source inventory and record-level provenance for the selected Metric package. It does not reauthenticate providers, establish the source's truth/completeness, assign truth to a locator, or create an interpretation.

## Inputs

| Required field | Type / source | Check |
|---|---|---|
| `input` | Exact normalized Metric input and all source references/locators | Each ref's source digest is among selected package files; record identity and scope are valid. |
| `sourcePackage`, `manifestArtifactSha256` | Exact source-package manifest and its artifact digest | Every selected source's path, digest, byte size, media type, evidence family, role, independence, provenance basis and period match manifest. |
| `selectedSources`, `rawByteMappings` | 2–5 distinct files and one mapping per file | Exact file bytes match digest/size; no duplicate selected digest; mappings match package ID, role, logical/export path and media type. |
| `lineage` | normalized-input digest, normalization receipt digest, metric-result digest | Each is valid SHA-256 and binds to the exact A30/A1 artifacts. |

Selected-file metadata and exact bytes are mandatory. A record's label ref may be null; it is reported as unlabeled, not filled. Source acquisition time may be null when not declared.

## Compatibility and procedure

1. Verify manifest and each selected file's exact bytes/digest. Require 2–5 selected sources, all distinct, with metadata exactly equal to manifest. Do not substitute an alternate source because a preferred locator is absent.
2. Walk normalized records in exact input order. For each record emit `recordIndex`, `/records/{i}` pointer and exact references to the record, revenue and units source digest/locator. Emit label reference or null. Reject a reference to unselected source.
3. Calculate coverage counts with denominator `recordCount`: nonempty record, revenue, units, label locators and unlabeled records. This is locator availability coverage in selected rows, not verified-evidence coverage or population coverage. Retain normalization and calculation digests and package identity.
4. Canonicalize `m13-provenance-appendix.json`, compute `methodOutputId`, validate and bind artifact into the exact report packet and replay chain.

Dedup unit is exact selected package-file digest; duplicate digests fail. Record lineage follows original normalized record order; repeated locator strings are not independently deduplicated because each row has its own pointer. Missing optional label stays null; observed zero remains a value in the upstream input. There is no price/market denominator, no percentage rounding and no inference from missing locators.

## Output, example and failure

Output includes `sourcePackage`, lineage digests, exact `sources`, per-row `recordLineage`, `coverage`, limitations and content ID. Synthetic example: 2 normalized rows each map record/revenue/unit to one of 2 exact files; row 1 label locator exists, row 2 label is null. Expected `recordCount=2`, record/revenue/units locator counts 2, label locator count 1, unlabeled count 1. The 50% label locator coverage describes these two rows only.

Blocked example: a row's revenue pointer uses an unselected file digest. Expected `M13_EVIDENCE_SOURCE_NOT_SELECTED`, no artifact. If package metadata says one byte size and exact file has another, reject even if JSON parses.

## Claims, review and dependencies

Allowed: “This normalized field points to locator L in file digest H in package P.” Link the exact M13 pointer and retained source locator. Forbidden: source true/authenticated, market complete, representative sample, complete label set, or proof that the source statement is correct.

AI role: none. Human verifies source-selection intent, locator interpretation and usage rights. Depends on exact source package, A30 normalized input, normalization receipt and A1 Result; feeds I03, I17 and report evidence navigation. No dependency on M01.

Proposed blockers: `M13_PACKAGE_MANIFEST_MISMATCH`, `M13_SOURCE_MEMBERSHIP_MISMATCH`, `M13_RAW_MAPPING_MISMATCH`, `M13_EVIDENCE_SOURCE_NOT_SELECTED`, `M13_LINEAGE_DIGEST_INVALID`. Reopen on new/removed file, byte/manifest/locator/normalizer/result/usage-right change. Acceptance: source-byte drift rejects the appendix (A23 owns); unlabeled row remains null and increments unlabeled count (A23 owns); complete locator coverage does not create a truth claim (report claim boundary owns). Existing package/replay integration is primary.
