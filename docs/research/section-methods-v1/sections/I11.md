## Question and boundary

Do already available comparable source data show a measured difference between owner-defined groups on the same outcome? The first output can be an unranked group/denominator inventory. No group definition, sparse-cell cutoff or uncertainty method is set here.

## Inputs and procedure

Required: owner-supplied group definitions/version and assignment source; same outcome/measure, unit, period and sampling frame; group numerator/value and denominator with exact source pointers; stable IDs or compatible source-provided aggregates; predeclared sparse-cell rule; predeclared uncertainty method if inferential claim is requested. No customer collection is proposed.

1. Freeze group definitions and policies before inspecting values. Confirm groups are mutually exclusive/exhaustive only if source/policy says so; otherwise keep overlapping groups separate and do not compare rates as if they partition a population.
2. Check compatible outcome definition, unit, period, inclusion/exclusion, source population and denominator. If any differ, mark `NOT_COMPARABLE`; retain separate cells without a delta.
3. If counts and nonzero denominators are compatible, calculate each rate as `numerator / denominator` and absolute rate difference as `rate_A − rate_B`, retaining exact fractions. If denominator is zero or count data are incomplete, rate/difference is null. Apply the predeclared sparse-cell rule before releasing group results. Apply only the predeclared uncertainty method; otherwise suppress statistical inference.
4. Show group values and uncertainty/limitation, with counterevidence. Do not rank groups by point estimate or infer why they differ. Person-level groups require real source-supported person identity; manual internal locators alone cannot create group membership.

## Output, example and failure

Output: group policy, source/group refs, outcome definition, numerator, denominator, rate, exact difference if allowed, suppressed/missing state, uncertainty method/result, sample frame and limitations. Toy fixture: owner-defined compatible A has 4/10 and B 3/10. Proposed arithmetic yields rates 0.40/0.30 and difference +0.10; this toy does not establish significance or an approved group cut.

Blocked fixture: A is a sales count in a full month, B is a review count in a different period. Expected `I11_DENOMINATOR_OR_MEASURE_INCOMPATIBLE`; no rate or group ranking. If sparse/uncertainty policies are absent, preserve raw compatible counts only.

Allowed: “For owner-defined groups and compatible denominator D, observed rate difference is …”, with uncertainty limits. Forbidden: protected/person-specific assertions from unlinked notes, causal group effect, prevalence or stable segment rank absent sampling/uncertainty authority.

AI role: none for group assignment, statistic or ranking. Human owner predeclares groups and sparse-cell/uncertainty rules and reviews interpretation. Requires group definitions and compatible source observations directly; may optionally reuse I02/M13 context and an already reviewed I16 result. No I16 completion is required for descriptive source cells. Open choices: group definitions, denominator, overlap, sparse rule, uncertainty method and publication suppression. Blockers: `I11_GROUP_POLICY_MISSING`, `I11_MEASURE_INCOMPATIBLE`, `I11_DENOMINATOR_MISSING`, `I11_SPARSE_POLICY_MISSING`, `I11_UNCERTAINTY_METHOD_MISSING`. Reopen on policy/data changes. Acceptance: no denominator means no rates; sparse policy is fixed before values; incompatible samples remain separate.
