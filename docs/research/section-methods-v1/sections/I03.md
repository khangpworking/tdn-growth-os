# I03 · Phương pháp nghiên cứu

Spec v1.0.0 · coverage `DRAFTED` · authority `EXISTING_BOUNDED_SUBMETHOD` · implementation `EXISTS_A25` · readiness `NOT_ASSESSED` · execution/review `NOT_RUN`.

## Question and boundary

How did one exact Metric source package become the normalized rows and calculated scopes consumed by this report? A25 records a deterministic method account and denominator/coverage trail. It does not establish whether the source is truthful, representative, market-complete, correctly labeled, or suitable for the business question. It is not a research conclusion.

## Inputs

| Required field | Type / source | Check |
|---|---|---|
| `m02`, `m13` and exact artifact bytes | A22 scope account and A23 provenance appendix | Canonical bytes, IDs, periods, selected sources and lineages replay and agree. |
| `receipt`, `receiptBytes` | A2/A30 exact normalization receipt | Canonical bytes; `inputSha256` and profile match exact result; receipt evidence rows align to records. |
| `result`, `resultBytes`, `normalizedInputSha256` | Exact A1 metric result and normalized input content digest | Canonical result bytes; result input digest equals receipt/input; package, period and source lineage match M02/M13. |
| Record inventory and scope membership | M13 recordLineage, M02 counts, Result ALL/WIDE/CORE rows | All denominators equal the normalized record count. |

All method-chain artifacts are mandatory. A row with null label remains explicitly unlabeled; no separate case-interview or new research collection is required.

## Compatibility and procedure

1. Replay canonical M02/M13, normalization receipt and Result bytes. Require equal normalized-input, receipt and result digests across the chain; match M02 scope and period exactly to the Result; require M02, M13, receipt-evidence and record-lineage counts all equal `result.input.records.length`.
2. Copy the source inventory from M13 and attach each exact `/sources/{i}` pointer. Set denominator `denominatorRecordCount = normalized record count`; record locator, revenue locator, units locator and label locator counts from M13. Set label denominator to the full record count. Copy labeled, unlabeled, UNKNOWN, OUTSIDE and adjudication counts from M02. Copy missing/observed-zero and non-exact values without collapsing them.
3. For ALL/WIDE/CORE, emit status, member count, full-record denominator and warnings from the exact Result. Do not calculate extra membership or convert a blocked scope to zero. Record M02/M13/normalization/result IDs and reopen conditions; canonicalize, validate and bind output.

The current join checks use the declared A1 platform, selection, start/end, period basis, metric profile/currency, label codebook and frozen UNKNOWN policy. The method handles one scope; it does not perform a cross-period/timezone comparison. Any future multi-period comparison needs a reviewed compatibility rule. Denominator is rows, not customers, product variants, all marketplace listings or market population. No dedup beyond the upstream `[platform, shopId, listingId]` uniqueness; no rounding for integer counts. Source inventory/order follows exact M13 order.

## Output, example and failure

Output `i03-research-method.json`: source-package identity, exact lineage, normalization profile/verification, measurement frame, source inventory pointers, coverage counts, ALL/WIDE/CORE membership, limitations and content ID.

Synthetic example: four normalized rows, all linked by receipt and M13, with four valid frozen labels and locators. Two labels are CORE_CANDIDATE, one UNKNOWN, one OUTSIDE; one revenue is missing and one is observed zero. Expected row denominator 4; member counts ALL 4, WIDE 2 under exclude-UNKNOWN policy, CORE 2; missing revenue 1 and observed-zero revenue 1 remain distinct. These numbers are only a toy fixture.

Blocked example: M13 says normalized input digest `hA`; A2 receipt binds `hB`. Expected `I03_LINEAGE_OR_SCOPE_MISMATCH`, no artifact. If denominator records differ by one across M02/M13/receipt, block; do not shrink the denominator.

## Claims, review and dependencies

Allowed: “The result was built from this exact selected input/package, profile, frame, row denominator and frozen label policy; locator/state counts are …”. Cite method artifact, M13 source and locator pointers, Result scope pointers and preparation digests. Forbidden: provider verified, source true, population coverage, representative sample, valid market measure, correct labels, insight, causality or effectiveness.

AI role: none. OWNER reviews frame, source meaning, locators and label policy. Depends on M02, M13, A2/A30 receipt and exact Result; supports I17 and later interpretation eligibility. No dependency on M01.

Proposed blockers: `I03_CANONICAL_BYTES_MISMATCH`, `I03_LINEAGE_OR_SCOPE_MISMATCH`, `I03_COVERAGE_DENOMINATOR_MISMATCH`, `I03_ALL_SCOPE_REQUIRED`. Reopen on membership/frame/profile/period/label policy/coverage/replay change. Acceptance: denominator disagreement blocks instead of silently changing N (A25 builder owns); missing vs observed zero remain separate (A25 output owns); exact source inventory pointers resolve to M13 (A23/A25 boundary owns). Existing package-to-I03 integration is primary.
