# I17 · Phụ lục và bằng chứng

Spec v1.0.0 · coverage `DRAFTED` · authority `EXISTING_BOUNDED_SUBMETHOD` · implementation `EXISTS_A26_DIRECTIONAL_TRACE` · readiness `NOT_ASSESSED` · execution/review `NOT_RUN`.

## Question and boundary

Can a reader follow each retained method fact and M03/M04 quantitative claim to the exact upstream artifact, digest, pointer, scope and denominator already responsible for it? A26 emits a directional reference index. `RESOLVED` means that the pointer exists. It is not proof, source truth, support validation, completeness, approval or provider authentication.

## Inputs

| Required field | Type / source | Check |
|---|---|---|
| `packet`, exact packet bytes, catalog digest | One exact report packet/catalog | Packet binds exact metric result, claims and method artifact descriptors. It must not already contain an I17 output identity that would cycle. |
| `result`, canonical result bytes | Exact M03/M04 metric Result named by packet | Exact bytes hash to packet Result digest; input identity matches. |
| `m02`, `m13`, `i03` | Exact methods and canonical artifact bytes | Mandatory; method output IDs, bytes and packet descriptors match. |
| `m08` | Exact A24 quote method and bytes | Optional; if present it must be the exact packet M08 descriptor and same package as M13/I03. If packet contains M08 but caller omits it, reject. |
| `packet.claims[]` | Existing M03/M04 `ClaimRef` set | Every claim's metric/scope/membership and optional denominator/coverage pointer resolves in the exact Result. Other section claims are unsupported by A26. |

## Compatibility and procedure

1. Validate canonical Result bytes, Result digest and normalized-input link against packet. Validate the exact method-file set: required M02/M13/I03; M08 only if packet declares it. Check canonical bytes, output IDs, filenames, method IDs, versions and exact packet descriptor digests.
2. Cross-check I03 lineage against M02/M13, their shared normalized input/receipt, Result and package. Cross-check optional M08 package identity against M13/I03. Reject any mismatch or unresolved pointer.
3. Create one `TRACE_FOR` entry for each exact method artifact using that artifact's declared source/lineage/coverage pointers and denominator pointer. Create `CALCULATION_BASIS` entries for M03/M04 claims, sorted by `claimId` code-unit order, with exact Result pointer(s), scope, membership, optional denominator/coverage and limitations.
4. Bind upstream package, catalog, normalized input, metric Result, claim-set digest and method artifact identities. Emit only upstream identities; final packet binds I17 later. Canonicalize and retain the I17 artifact with `RESOLVED_REFERENCES_NOT_SOURCE_TRUTH` state.

Dedup unit is section ID plus exact method-output identity; duplicate/conflicting method inputs fail packet-set checks. Claim order is deterministic. Missing, zero, UNKNOWN and non-exact states are unchanged. A missing optional M08 is not a blocker. No new numeric denominator is calculated; pointer denominator is inherited. No ranking, rounding or aggregation occurs.

## Output, example and failure

Output includes `upstreamBinding`, `entries`, resolved/unresolved and artifact/claim/method counts, status and limitations. Synthetic example: one M03 claim points to Result `/scopes/0/revenue`, scope `/scopes/0`, membership `/scopes/0/recordIndices`, denominator `/scopes/0/listingCount`. If all four pointers resolve, entry status is `RESOLVED`; it preserves the numeric state and says nothing about whether listing count is an appropriate commercial denominator.

Blocked example: claim points to `/scopes/9/revenue`, which is absent. Expected `I17_UNRESOLVED_CLAIM_POINTER`; no index. If I17 output were embedded into the packet whose digest it depends on, that would create a cycle and is forbidden.

## Claims, review and dependencies

Allowed: “This claim points to exact Result pointer P, in scope S, with denominator pointer D.” Link directly to artifact and pointer. Forbidden: “I17 validates/supports/proves the claim”, source authenticity, completeness, representativeness, true period/labels, causal/effectiveness conclusion or recommendation.

AI role: none. A human reviews whether linked sources are intelligible and usage rights permit report inclusion. Depends on M02, M13, I03, exact Result/packet/catalog/claims and optional M08. Downstream final packet, semantic content, report version and evidence navigation consume its digest; no circular upstream dependency and no M01 prerequisite.

Proposed blockers: `I17_RESULT_OR_PACKET_MISMATCH`, `I17_METHOD_FILE_IDENTITY_MISMATCH`, `I17_METHOD_LINEAGE_MISMATCH`, `I17_UNRESOLVED_POINTER`, `I17_CIRCULAR_IDENTITY`. Reopen if any source/digest/claim/pointer/denominator/codebook/policy/method/rights change. Acceptance: unresolved JSON Pointer blocks output (A26 owns); optional M08 absent is permitted only when the packet descriptor is absent (A26 owns); I17 never points to its final packet identity (directional binding owns). Existing cross-layer integration is primary.
