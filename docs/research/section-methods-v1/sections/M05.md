# M05 · Nhu cầu

Spec v1.0.0 · coverage `DRAFTED` · authority `PROPOSED_OBSERVATIONAL_METHOD` · implementation `NEW_CODE_IF_APPROVED` · readiness `NOT_ASSESSED` · execution/review `NOT_RUN`.

## Question and boundary

What existing evidence signals demand-related activity in a declared scope? This proposal records each declared proxy separately; it does not estimate total unmet/latent demand or convert sales, search activity, reviews, or co-occurrence into demand by default. It requires already available source data, not new interviews or surveys.

## Inputs

| Required | Typed fields and checks |
|---|---|
| Owner method declaration | `{proxyId, proxyDefinition, evidenceFamily, observationUnit, targetPopulationOrScope, intendedInterpretation}`; owner must approve the proxy's meaning before calculation. |
| Existing source records | `SourceFileRef`, exact row/quote locator, observed date/period, proxy value or explicit `missing`/`observed_zero`, unit, selection/sampling frame and source-reported population if any. |
| Optional denominator | `{value, unit, populationDefinition, period, sourceRef}`; required only for a rate/share. It must measure the same universe and period as numerator. |
| Optional anchor/comparison | Same proxy, unit, definition and compatible period from an existing source; no inferred baseline. |

## Procedure and compatibility

1. Freeze owner proxy declaration and exact corpus/package digests. Verify each value is directly present in source or has a reviewed deterministic normalization with locator; do not infer proxy from a broad section title.
2. Partition observations by proxy ID, source period, unit, geography/entity scope and sampling frame. Keep incompatible groups separate. Deduplicate only by an existing stable source record key; otherwise count located source records and label the count as records, not people/searchers.
3. For a declared additive measure, sum only observed values using exact source units; emit observed count, missing count, zero count, non-exact count and period. Emit a rate only as `numerator / owner-supplied compatible denominator`; if denominator is absent, zero, or incompatible, rate is null with blocker. Never sum different proxy families into one demand score.
4. State competing or contradictory signals side by side; don't choose one using recency/source count. Output one `proxyObservation` per compatible partition with claim eligibility and limits.

Missing is not zero. A sample's unseen value is missing, not no demand. Ties/order follow source locator then exact source digest only for stable rendering; no business ranking. No confidence, prevalence, market size or causal link is calculated.

## Output, example and failure

Proposed output fields: `proxyId`, definition/version, source refs/locators, frame, period, unit, numerator/value state, optional denominator, computed value/rate, coverage counts, contradictions, limitations, blocker list and `PROPOSED/UNREVIEWED` state.

Toy fixture: an already-existing source provides two located counts 12 and 8 under one owner-declared additive proxy and matching period/unit. Expected descriptive subtotal 20 source units, `n=2` records. No population rate appears without a compatible denominator.

Blocked fixture: a report author labels 20 sales as “demand” without an approved proxy definition. Expected `M05_PROXY_NOT_AUTHORIZED`; keep sales as sales and emit no demand claim.

## Claims, ownership and open choices

Allowed: “Source X reports proxy value 20 for frame F and period P.” Link each component to source locator. Forbidden: total addressable market, unmet demand, people count/prevalence, causal demand driver, purchase intent, or conversion from sales absent approved interpretation.

AI role: none for proxy selection, data extraction as evidence, aggregation, or numeric claims. Human owner chooses/approves proxy, target scope, interpretation and denominator. Depends on M02 scope and M13 provenance when available; does not depend on M01. Downstream M01 may summarize eligible source-bound claims.

Open parameters: proxy catalog and definitions; source family eligibility; additivity; population/frame; denominator; period; missing/non-exact policy. Proposed blockers: `M05_PROXY_NOT_AUTHORIZED`, `M05_FRAME_INCOMPATIBLE`, `M05_DENOMINATOR_MISSING`, `M05_SOURCE_LOCATOR_MISSING`. Reopen on changed declaration, source, period or denominator. Acceptance: same-period additive proxy sums to 20 (future calculation owner); a missing denominator returns no rate (future contract); sales-only input cannot claim demand (business authority gate). These are proposals, not approved runtime codes.

Aggregation prerequisite: record aggregation granularity and disjoint entity/time membership before summing. Matching unit/period is insufficient. A total plus its subtotal or alternate representation remains separate; unresolved overlap blocks the sum, not the inventory. See common-rules.md.
