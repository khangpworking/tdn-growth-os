# M08 · Giá và kinh tế đơn vị

Spec v1.0.0 · coverage `DRAFTED` · authority `EXISTING_BOUNDED_SUBMETHOD_ONLY` · implementation `EXISTS_A24_M08_P4` · readiness `NOT_ASSESSED` · execution/review `NOT_RUN`.

## Question and boundary

What exact declared single-quote packaging arithmetic follows from one exact raw quote and its canonical quote input? The only implemented slice is `M08/P4 · Chuẩn hóa giá quote viên đơn lẻ`, marked `SCENARIO`, `UNREVIEWED`, `DECLARED_UNVERIFIED`, `NOT_AUTHENTICATED`. It does not calculate costs, payouts, margin, willingness to pay, unit economics, comparative price, dose equivalence or recommendation.

## Inputs

| Required field | Type / source | Check |
|---|---|---|
| `sourcePackage` | Exact finalized package identity: ID/key/version, manifest and content digests, acquired/finalized times | Both digests are 64-char lowercase SHA-256 and selected files are members of this same exact package. |
| `rawSource` | One `tabletQuoteSource` JSON `SourceFileRef` and exact bytes | Hash, size, media type and package path replay; ≤32 MiB. |
| `quoteInput` | One distinct `tabletQuoteInput` JSON source from same package with exact bytes | Hash/size/media/path replay; points to the raw quote digest; canonical input passes `tablet-quote-input` v1 schema. |
| Quote fields | Required schema fields: `quoteId`, `sourceRef` locator, `observedAt`, `observationPeriod`, `observationTimeState`, `entityTitle`, `packText`, `packCount` (nullable), `priceVnd` (nullable), `priceState`, identity/variant/GTIN/version status, `sourceRole`, currency VND | `KNOWN` requires observed-at or period (both may be present); `UNKNOWN` requires both null. A supplied pack count is a positive integer and OWNER_DECLARED. |

Both files are mandatory. `packCount` and `priceVnd` may each be null as declared inputs; they are not inferred from title, image or other quotes. Listed and checkout prices stay distinct.

## Compatibility and procedure

1. Replay exact package manifest and the two distinct JSON files. Require each source's role/path/digest/size/media metadata to agree with package membership. Reject a quote input that points at another raw quote digest.
2. Normalize the canonical quote input using `tablet-quote-normalization-v1`; parse decimal strings as exact rational values. `pricePerPack = priceVnd` when present. If both price and owner-declared tablet count exist, calculate exact `pricePerTabletArithmetic = priceVnd / packCount` as a reduced rational. Do not replace this arithmetic with a rounded integer.
3. Render only the declared VND display to two decimals using half-even. Preserve exact rational numerator/denominator and rounding-version tag. For each unavailable calculation, return null exact/display value and the exact missing input names.
4. Bind the raw input digest, normalized output digest, package and source metadata into `m08-tablet-quote-method.json`; validate canonical content ID and retain. Exact report retry reuses the same retained output.

Dedup unit is the exact package path + digest; paths must differ and quote ID is the supplied method-local ID. This method handles exactly one quote, so it has no ranking or tie rule. No market denominator exists; tablet count is a packaging denominator only. If price is missing, price/pack is unavailable; per-tablet result is unavailable with `priceVnd`. If pack count is missing, per-tablet result names `packCount`. A zero price is allowed as an observed quote input, not recoded as missing. No rounding is applied to exact arithmetic itself.

## Output, example and failure

Output `m08-tablet-quote-method.json`: exact `sources`, package identity, raw/canonical/normalized digests, normalized `quote`, exact rational and display outputs, source/approval state and limitations.

Synthetic example: input price `240000` VND, owner-declared count `60 TABLET`, `priceState=DISPLAYED_LISTED`. Expected exact per-tablet ratio `4000/1`; display `4000.00`, half-even v1. Price per pack remains 240000. This is not an observed verified commercial fact.

Blocked example: quote input references a raw-source digest absent from the selected package. Expected `M08_SOURCE_REF_DIGEST_MISMATCH`, no artifact. If the pair is absent, broader M08 remains blocked. A conflicting variant or unknown identity status is retained as supplied, never upgraded.

## Claims, review and dependencies

Allowed: “This unreviewed scenario quote declares X VND per pack; given an owner-declared count of Y tablets, exact arithmetic is X/Y VND per tablet.” Cite both file hashes, locator, `priceState`, observation-time state, exact numerator/denominator and limitations. Forbidden: quote comparison/rank; real market price; authenticated source; equivalent dose/effect; cost/margin/profit; forecast, WTP or recommendation.

AI role: none. A human validates package selection, quote meaning, price state, operator count and whether the narrow arithmetic is useful. Depends only on the exact pair and finalized package; I17 may trace it when present, but its absence does not block I17. The broader M08 scope needs separately reviewed costs, payouts, returns, eligibility and fee version; none is invented here.

Proposed blockers: `M08_PACKAGE_MISMATCH`, `M08_RAW_QUOTE_INVALID`, `M08_QUOTE_INPUT_INVALID`, `M08_SOURCE_REF_DIGEST_MISMATCH`, `M08_PAIR_MISSING`. Reopen if either source, count, price, status, package or normalizer version changes. Acceptance: exact fractional division is replayed (normalizer owns); a null pack count produces unavailable per-tablet arithmetic (normalizer owns); one-source/no-source package cannot create P4 (A24 boundary owns). No broader-unit-economics test is implied.
